## skill 可分发打包与 DSH 插件安装说明

**背景**：skill 之前只在仓库里，要发给别人或传到公开技能市场，得手动挑文件；DSH 用户拿到 skill 后也不知道还有插件壳可装——`SKILL.md` 只写了「已经在插件壳里」
怎么办，没写怎么进去。

**改法**：

- `SKILL.md` 在「在 DSH 插件壳里」之前加一节「用户想装 DSH 插件时」：只给 npm 安装指引
  `dsh plugin --profile web add dsh-cyber-im-avatar`，不替用户执行、不主动推荐；插件负责
  轮询 / 水位 / 唤醒，并把本 skill 装到 `~/.agents/skills/cyber-im-avatar/`。
  文件树补 README / CHANGELOG / LICENSE / tests。
- 新增 `scripts/package_skill.py`：生成 `dist/cyber-im-avatar/` 与同名 zip，只带 SKILL.md /
  README / CHANGELOG / LICENSE / references / scripts（运行时八个）/ tests（run_tests +
  mock_cli）；按技能市场上传校验预检 frontmatter（根目录 SKILL.md、name `[a-z0-9_-]+`、
  description 非空）。
- `.gitignore` 加 `dist/`；README 安装段补一行打包命令；`scripts/doc_budgets.json`
  SKILL.md 460→475。

**验证**：

- `python3 scripts/package_skill.py`：18 个文件 382 KB，zip 150 KB；根目录 SKILL.md，
  frontmatter `name=cyber-im-avatar`。
- `cd dist/cyber-im-avatar && python3 tests/run_tests.py`：182 通过 / 0 失败；
  插件与文档对账按包内缺席自动跳过（`f2e4042` 的分发分支）。
- `bash scripts/gate.sh --quick` 与全量 gate 全绿；仓库 `python3 tests/run_tests.py`
  213 通过 / 0 失败。
- 未发 npm 版；`dist/` 不进版本库，本地已装的 skill（`~/.agents/skills/cyber-im-avatar/`）
  与插件内副本（`dsh-plugin/skill/`）已用 `bundle-skill.mjs` + `ensureSkill()` 刷新。

**下一步**：把 `dist/cyber-im-avatar/` 选进技能市场的「上传 / 更新技能」；要发 npm 版时
按 `docs/implementation/runbooks/publish.md` 涨号。
