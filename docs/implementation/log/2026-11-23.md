## 0052 私聊进度卡：从“计时器”改成“动作计数”

**背景**：实际 值班工作区 65 个超过 2 分钟的客户 turn（43 p2p / 22 群），
10 个最长 p2p（11–23 分钟）里 `[进度]` 标记 **0 条**，`todo/write` 也为 0。只显示
“处理中”或纯计时器不能证明在工作，决定用 tool call 分类计数作为卡片第一行。

**改动**：

1. `lib/progress.js`：`actionCategory` 只读 `tool/call.name`，归到查资料 / 改文件 /
   执行操作 / 并行处理；`buildProgressCard` 第一行固定“已做：… N 次”；`[进度]` 可选，
   解析任务级现在/接着/第 n/m 步；2 分钟建卡；心跳从建卡起 10/30/60 秒；进程重启扫尾。
2. `lib/state.js`：`dsh.progress_card=false` 默认关；`chats[].progress_card` 三态
   null/true/false；`chats[].progress` 落卡片状态与计数；`normalizeProgress` 只留 ids 5 条。
3. `lib/app.js`：`POST /api/chat/progress` 写单聊三态；`/api/config` 合并全局 `dsh.progress_card`。
4. `lib/im.js`：飞书 `cmd_send_card` / `cmd_send_card_user` / `cmd_patch_card`，本人身份；
   `sendCard` 必须拿到 message_id；`patchCard` 的 `--data` 包 `content` 字符串。
5. `lib/turns.js`：`ProgressCards.begin/note/finish/stopAll`；载荷只在生效时声明进度卡，
   `announcedPolicy.progress_card` 变化才重带，压缩后重带。
6. `lib/poller.js`：`progress.ids` 不进 selfEpoch / recent / newIds，`best` 仍推进水位。
7. 面板：设置页全局开关；私聊详情三态“跟随全局 / 开 / 关” + 状态；群聊不显示。
8. 契约 01/02/03、skill 两份、README、插件 README、CHANGELOG 未发布同步；重建 client。

## 0053 引用消息进载荷

**触发**：2026-11-23 14:51 真机。本人在飞书私聊回复更早一条「查一下网关配置，给个解释吧」，
回复正文只写「@示例本人」。DSH 收到的载荷行只有回复正文，引用关系与原文都丢了，
agent 看不出要查什么。

**实测**（lark-cli 1.0.98，本机）：

- `+chat-messages-list` 每条带 `reply_to`（被引用消息的 `message_id`，字符串）；引用正文不在列表里。
- `+messages-mget --message-ids <id1,id2> --as user` 一次可传多个，返回 `data.messages[]`，
  `content` / `create_time` / `sender` / `msg_type` 与列表一致；任一个 ID 失效会整组 `ok:false`
  （code 99992354），所以 ≤4 个时逐个查、多了再 20 个一组。
- 私聊样本：最近 10 条里 3 条带引用，3 条全部解析成功，其中 2 条目标不在本批、走了 mget；
  单次补引用约 2.4s（2 次 CLI），命中本批时 0 调用、0ms；第二轮克隆对象再解析，缓存命中、0 次 mget。
- 群样本：50 条历史里 5 条带 `reply_to`，说明群聊同样常见。

**改动**：

1. `lib/im.js`：飞书 `f_reply_to`（`reply_to` / `parent_id` / `root_id`）与 `cmd_mget_quote`
   （不带 `--download-resources`）；`norm()` 带 `reply_to`；`resolveQuotes()` 先吃本批、
   按 `since` 只补新消息、缓存成功 30 分钟 / 失败 2 分钟（上限 500），mget 失败只记「取不到」。
2. `lib/state.js`：`recent` 追加 `reply_to` / `quote`，与正文同生命周期；`mergeRecent` 只补空。
3. `lib/poller.js`：`pollChat` 在 `process` 前按水位补引用；`fetchThread` 也给面板补；
   `classified` 与 `commandRow` 带上两字段。
4. `lib/turns.js`：`formatMsgLine` 追加缩进 `↪ 引用 [ts] 谁: 原文`；媒体引用只给标记 + `msg_id`；
   取不到写「原消息取不到」；本批有引用时加一句「缩进行只作上下文」；正文清洗 / 单行 / 截 300 字。
5. 面板会话详情显示引用行；`python3 scripts/build_client.py` 重建 `lib/client.js`。
6. 契约 01/02、`SKILL.md`、`references/{feishu,wecom,dingtalk}.md`、`docs/architecture/03-runtime.md`、
   `CHANGELOG.md` 未发布同步；spec 0053 + plan 落 `docs/specs/active/`。
