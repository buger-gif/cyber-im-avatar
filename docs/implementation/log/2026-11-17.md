## 值守静默的两个坑：@ 自己 被吞、没 @ 你没解释

**背景**：面板报「接口报错 2200」来查，最后查出两件事都不是它。

- 2200 是飞书侧通用内部错误（等价 5xx），凭证与权限都正常（`auth status`
  `tokenStatus=valid`，到期 11:51），复跑 `+chat-list` / `+chat-messages-list` /
  `+messages-search --is-at-me` 全部 ok；值守会话 `last_sync` 每分钟都在推进、
  `last_error` 全空。面板那行是**没被清掉的内存错误**：`this.errors` 只进不出，
  一次抖动会一直挂到插件重启。本次没改它，先记着。
- 真正的问题在「值守中却不处理」。查 `state.json` 定位到两处：
  1. `10:24` 本人 @ 自己 + 「启动」，命中关键词后 `startDutyFromCommand` 判 `already`，
     整条进 `consumed` 被从唤醒批次摘掉——不建会话、不给 agent、也不发回执。
  2. 那个私聊 `wake_mode=mention`，对方 `10:08/10:09/10:21/10:23` 四条
     `mentions` 全是 0 → 全判 `fyi/ignored`。值守只管「拉不拉」，唤醒条件是配置出来的，
     面板只有「值守中」一个标签，看不出被静音。

**改法**：

- `consumeStartCommands` 只在真开了会话（`started`）时消费；`already` 留给唤醒批次。
  扫描先命中、下一轮又捞到的重复 `started` 仍消费，避免对同一条指令叫醒两次。
- 新增 `recent[].skip` 原因码（`baseline` / `no-mention` / `you-replied`），
  `GET /api/chats` 加 `silent: {count, skip}`（排除 `baseline`）、`/api/thread` items 带 `skip`；
  面板值守卡片与会话详情各挂一行「最近 N 条没有唤醒：没 @ 你」。
  不升 `STATE_VERSION`，老数据缺键按空串。

**验证**：

- `node --test`：305 通过 / 0 失败（新增 state 白名单、poller 三种原因、app 汇总与 thread 透出）。
- `bash scripts/gate.sh --quick` 全绿；spec 0049 的验收除「面板真机看一眼」外全勾。

**没做的**：

- 私聊「只盯 @我」防呆（P1）：这个档位在私聊几乎等于静音，面板只有一行灰字。
- 切模式后的回补（P2）：`mention → all` 是 forward-only，老消息仍是 `ignored` 且正文没落盘。
- 错误内存缓冲的过期（2200 那行一直挂）：`this.errors` 不过期，只靠重启清。

## 关注页可直接编辑日报（spec 0050）

**背景**：会话工作本与人物档案都能在面板里直接改，关注页的每日摘要却只能看。用户要求补编辑，
方便自己删掉已处理项、补判断或改措辞。

**改法**：

- 新增 `POST /api/digest`：`date` / `text` / `base_mtime`。整份覆盖写，目录 700、文件 600、
  临时文件 + rename；超 256 KiB 拒绝不截断；空白内容 = 删除当天文件；磁盘 mtime 与
  `base_mtime` 不一致（含 agent 新建 / 删除）回 `stale` 不写。GET 与写接口共用 `digestFile()` 的严格日期 + 目录内路径校验。
- `GET /api/digest` 加 `truncated`：超过 256 KiB 时面板只显示前段，且不给编辑入口，
  避免把截断内容保存回去毁掉后半段。`mtime` 改为精确秒（带小数），否则面板拿整秒去比对
  分秒级写入会误判 stale。
- 面板：关注页「编辑」进入整份 textarea；编辑期间冻结 3 秒静默刷新与 60 秒兜底刷新；
  stale 时不丢草稿，取最新 mtime 后第二次点「覆盖保存」才替换，另给「重新载入最新」；
  空态可新建，清空保存回到空态；Esc / 取消丢弃草稿。
- `SKILL.md §值守日报` 补：用户可能手改，更新时把当前文件当底稿，不补回用户删掉的行、
  不改写用户措辞。插件不判断哪行是谁写的。
- 演示夹具 `scripts/demo/fixture.mjs` 补 `POST /api/digest`，截图 / 演示页也能编辑。

**验证**：

- `cd dsh-plugin && node --test`：309 通过 / 0 失败（新增 4 条 digest 读写测试：
  写读/空删/权限与临时文件、非法日期与 256 KiB、截断标记）。
- `bash scripts/gate.sh --quick` 全绿（py-compile / js-check / docs / contracts / secrets）。
- 隔离 DSH（`IM_STANDIN_DIR=/tmp/im-standin-ui-0050`）+ headless Chrome/CDP，虚构日报：
  保存后正文立即更新并退出编辑；模拟 agent 抢写 → 冲突条 + 草稿保留 → 覆盖保存成功；
  「重新载入最新」换成 agent 版本；超限文件只提示不可编辑；空态新建 / 清空删除都回到空态；
  Esc 与取消不写盘。全部通过。

**踩坑**：第一轮 CDP 里保存成功、磁盘已写，但面板没退出编辑。原因是脚本用
`element.click()` 不移动焦点，`typingFocus()` 看到 textarea 仍有焦点就跳过 `paintBody()`。
真实鼠标点击通常会把焦点移到按钮，但不能把行为押在浏览器默认上；给 `paintBody(force)`
加显式强制重绘，保存 / 取消 / 冲突 / 重载都传 `force=true`。

**没做的**：不做版本历史 / 撤销 / 自动保存；冲突只做「二次确认覆盖」与「重新载入」，
不尝试自动合并；agent 下一轮是否尊重手改仍靠 `SKILL.md` 协议，插件不校验。
