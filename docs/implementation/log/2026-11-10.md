# 2026-11-10

## web 启动审计误报 `import failed`（spec 0042，待真机）

### 现象与读数

桌面 app（0.2.2-rc.1）17:26 启动，诊断报告：

```
Error: web boot: 1 entry did not activate
dsh-cyber-im-avatar: import failed (see console for the import error)
```

`~/Library/Logs/DeepSeek Harness/` 里同类文件共 6 份（11-03 ×2、11-05 ×2、11-06、11-10），
全部只点名这个插件。但同时：live Client 的 `sidebar.footer.action` 里
`dsh-cyber-im-avatar` 为 active，`~/.im-standin/state.json` 正常写、日志有 `[im-standin] ready`。

### 定位过程（含失败尝试）

1. `node -e import lib/index.js` 正常；`node --check lib/client.js` 正常；
   用假 window/React 执行 `__ModuleLoader__.load` 的 factory 正常 → bundle 与入口都没坏。
2. 用 `~/.dsh/runtime`（0.2.1-rc.5，与 11-03/05/06 日志同版本）起隔离 dev DSH，
   headless Chrome + CDP 抓 `Runtime.consoleAPICalled` / `exceptionThrown`，
   `window.__DSH_BOOT__` 里有该行、控制台零报错 → 干净冷启动复现不出来。
3. 读 DSH 构建产物（`app.asar` 内 `dsh-web-frontend` 的 `qZ`、`dsh-client-modules` 的
   `system.ts`/`entries.ts`、cordis loader 的 `Entry._init`）：
   - 通用文案 = entry 无 fiber 且 `importErrors` 没记录；
   - `Entry._init` 导入失败只 `logger.error` 后 return（不会自愈），而插件后来自己挂上了；
   - 说明审计看到的是**还没结算的导入**。
4. 桌面端 `dsh-desktop-host` 在 Host `ready` 时把 `webServer.collectIndexInjections()`
   快照给 Electron；页面之后还会经 HMR 图 `reconcile` 补建 entry，而启动审计只 await 了
   `entries.start()` 的队列 → 竞态。

结论与上游补丁草稿：`docs/audits/2026-11-10-web-boot-audit-race.md`。

### 改了什么

- `dsh-plugin/package.json`：`dsh.client.immediately = true`（页面在 entries.start 前预取该行）。
- `dsh-plugin/lib/index.js`：静态 import 只剩 `node:crypto/path/url`；9 个重模块改为
  `bootOnce()` 内并发 `import()`，`ensureSkill` 改为 apply 内异步 import；
  `boot()` 变 memoized Promise（失败清 memo 重试），`handler` await 它，`shutdown` 清 memo。

入口导入实测（`performance.now()` 包住 `import()`，各 5 次）：约 12–16ms → 3.7–5.4ms。

### 验证

- `cd dsh-plugin && node --test`：245 条全绿。
- 隔离 dev DSH + CDP 冷启动：`rowPresent=true, immediately=true, seat=true,
  apiOk=true, hostReady=true`，控制台只有 `seat mounted` / `dock tab registered`；
  宿主日志唯一的 warning 是 `schedule`（旧 runtime 读新版 storages，与本插件无关）。
- `bash scripts/gate.sh --quick`：见提交前结果。

### 待办

- 真机：重启桌面 app，确认 `~/Library/Logs/DeepSeek Harness/` 不再新增 `*-web-boot.log`。
- 上游：把 audit 文件里的补丁草稿提给 DSH（审计等 `entries.whenIdle()`；
  `import()` 的 not-a-row 分支记 `importErrors`）。
