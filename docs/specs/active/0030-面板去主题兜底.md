# 0030 面板去主题兜底

> 状态: 实施中
> 编号: 0030
> 版本: 0.13.1
> 关联: `dsh-plugin/web/panel.js`、`dsh-plugin/scripts/demo/standalone.html`

## 背景

面板配色从 spec 0007 起跟随 DSH 主题；2026-11-03 改成 `var(--dsw-*, fallback)` 加
`body[data-ds-dark-theme]` 覆盖（`docs/implementation/log/2026-11-03.md §面板配色跟 DSH 主题走`）。
当时的理由是 DSH 公开 token 只覆盖部分语义，所以面板自带一份浅色调色板兜底，深色再覆盖一遍。

现在宿主已经把这件事做完了：

- `@deepseek-ai/dsh-client-ui-theme` 的 README 要求功能插件「在 CSS 中读取 `--dsw-*` token；
  不自行管理主题状态」；
- `@deepseek-ai/dsh-client-ui-layout` 的 `apply(snapshot)` 把 token 以行内变量写到 `body`，
  同时设置 `document.documentElement.style.colorScheme` 与 `body[data-ds-dark-theme]`；
- 面板 `web/panel.js` 的 CSS 块 211 行里，30 处 `--dsw-*` 带了 `#hex` 兜底，深色覆盖块
  14 行（含注释）只是把同名 token 再指一遍，另有 13 行类规则在面板 DOM 里已无引用。

用户反馈「CSS 乱七八糟」，要「直接跟随 DSH 自身的」。

## 目标与非目标

- 目标：面板颜色**只**读 `--dsw-*` token，不再维护自己的浅/深调色板；删掉重复的深色覆盖块与死规则。
- 目标：在注入同样 token 的界面上，浅色/深色截图与改动前逐像素一致。
- 非目标：不改布局、间距、字号、圆角、控件形态；不改 JS 行为、接口、`state.json`、配置键。
- 非目标：不等价于「删光 CSS」。DSH 不给第三方插件提供组件或工具类，插件仍须自带布局样式。
- 非目标：不把 14 个主题包内部 token（`label-tertiary` / `bubble` / `toast-*` 等）换成
  公开的 14 个；那会丢文字层级、气泡与 toast 配色，反而更不像 DSH。
- 非目标：不把 CSS 抽成独立文件；本次只删不加。

## 方案

### 1. 颜色只留 token，不留值

`.ims-root` 的变量表改成纯映射（如 `--fg:var(--dsw-alias-label-primary)`）；`KIND` 映射、
用户气泡、toast 同样去掉 `, #hex`。`--r` / `--r-sm` / `--mono` / `--font` 保留兜底——它们不是
颜色，独立预览页与用户自定义字体缺失时仍要有可读的字形。

### 2. 删深色覆盖块

整段删除 `body[data-ds-dark-theme] .ims-root, html[data-ds-theme-source=dark] .ims-root{...}`
（含上方说明注释）。浅/深只由宿主注入的 token 值决定，`color-scheme` 已经由 `ui-layout` 设在
`<html>` 上；产品代码不再读主题属性。

### 3. 删死规则

`.ims-switch`（4 行）、`.ims-code`（2）、`.ims-notes`（1）、`.ims-note-at`（1）、
`.ims-note-del` 与 hover（3）、`.ims-section`（1）、`.ims-warnchip`（1），共 13 行。删除前用
`grep` 确认 `web/panel.js` 与 `lib/client.template.js` 都没有引用。

### 4. 独立预览页自带假宿主 token

`scripts/demo/standalone.html` 增加一段仅预览用的 token 定义：浅色挂 `body`、深色挂
`body[data-ds-dark-theme]`，值取 `dsh-client-ui-theme` 里 `design-platform.css` 的解析结果
（20 个颜色 token）。这段只服务 UI 走查，产品代码不依赖。

### 5. 重建产物

`python3 scripts/build_client.py` 重新生成 `lib/client.js`；`tests/test_docs.py` 会校验
`client.js` 与 `panel.js` 一致。

## 取舍

| 备选 | 否掉的理由 |
| --- | --- |
| 保留兜底，只删死代码 | 没解决「自带调色板」：token 缺失时是另一套值，等于两份事实 |
| 连非公开 token 一起换成公开 14 个 | 丢三级文字、气泡、toast 配色，面板更不像 DSH |
| 抽成 `web/panel.css` | 与本次「只删」目标无关，单独再做 |
| 引入 DSH 内部组件 | 插件验证规范明确禁止 import `@deepseek-ai/dsh-client-ui-primitives`，宿主机也没有公开组件 API |

## 影响面

- 代码：`dsh-plugin/web/panel.js`、`dsh-plugin/scripts/demo/standalone.html`、
  `dsh-plugin/lib/client.js`（构建产物）
- 文档：`dsh-plugin/README.md §外观`、`CHANGELOG.md`、`docs/implementation/PROGRESS.md`、当日 log
- 契约：无（不动路由 / state / 配置键）
- 用户可见：视觉不变；只是不再自己维护调色板
- 兼容：极老 DSH 若没注入 token 会掉色；但插件依赖的右侧栏服务与 `ui-theme` 同代，接受

## 风险与回滚

- 风险：宿主未注入 token（极老 DSH 或非 DSH 嵌入）时颜色落空；正常使用与预览页不受影响。
- 回滚：revert 该 commit；纯样式改动，没有数据迁移、没有配置影响。
