# 0048 启动值守后回一条回执 — 实施计划

> 关联 spec：`docs/specs/active/0048-启动值守回执.md`

## 步骤

1. **纯函数与配置归一**：`lib/command.js` 加 `replyText` / `replyEnabled` / `replyTooLong`；
   `lib/state.js` 的 `DEFAULT_CONFIG.command` 加两键，`normalizeConfig` 保留两键，
   `normalizeChat` 补 `command.reply`。
   验证：`node --test tests/command.test.mjs tests/state.test.mjs`。

2. **启动后发送**：`lib/poller.js` 在 `turns.open()` 成功分支调用 `sendStartReply()`；
   `writeCommand()` 保留 `reply`。
   验证：`node --test tests/poller.test.mjs`（新增 started 发 / already 不发 / 发送失败仍 started）。

3. **配置接口与契约**：`lib/app.js` 校验 `reply_text` 超长；同步
   `docs/specs/contracts/{01-api,02-storage,03-config}.md`。
   验证：`node --test tests/app.test.mjs` + `python3 tests/test_docs.py`。

4. **面板**：`web/panel.js` 设置卡加回执开关 / 文案，会话详情显示回执结果；
   `python3 scripts/build_client.py` 重建 `lib/client.js`。
   验证：`python3 tests/test_docs.py` 的构建产物新鲜度检查。

5. **文档**：`README.md`、`SKILL.md`、`dsh-plugin/README.md`、`CHANGELOG.md` 未发布小节、
   `PROGRESS.md`、当日 log。
   验证：`python3 scripts/verify_docs.py`。

6. **收尾**：`bash scripts/gate.sh --quick` 全绿；真机由用户在未值守的飞书群验证。
