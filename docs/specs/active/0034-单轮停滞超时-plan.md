# 0034 实施计划：单轮停滞超时

> 配套 spec：`docs/specs/active/0034-单轮停滞超时.md`
> 原则：一步一验证；每步绿了再下一步；契约与代码同 commit。

## 阶段 1 · 看门狗与配置

- [x] `lib/turns.js` 增加模块级 `turnWatchdog()`：`start()` / `touch()` / `stop()`，
      停滞触发 `onTimeout("timeout")`、总上限触发 `onTimeout("turn_cap")`；计时器 `unref()`。
- [x] `runTurn()` 删掉单枚墙钟 `timer`，改挂看门狗；`session/event` 监听里先 `touch()` 再 `collect()`；
      `settle()` 调 `stop()`；`onTimeout` 复用原超时分支（`cancelled + timedOut + cancelHandle + finish`）。
- [x] `lib/state.js`：`DEFAULT_CONFIG.dsh.turn_cap_sec = 3600`；
      `normalizeConfig()` 里 `d.timeout = int(d.timeout, 120, 3600, 600)`、
      `d.turn_cap_sec = int(d.turn_cap_sec, 0, 24 * 3600, 3600)`。
- 验证：`node -e` 直接 `import("./lib/state.js")` 跑 `normalizeConfig({dsh:{timeout:1,turn_cap_sec:-5}})`
  → `{timeout:120, turn_cap_sec:0}`。
