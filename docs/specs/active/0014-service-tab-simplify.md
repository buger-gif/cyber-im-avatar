# 0014 分身 tab 收敛为「值守列表 + 统一搜索」

> 状态: 已验收
> 编号: 0014
> 版本: 0.8.x
> 关联: `docs/specs/contracts/01-api.md`

## 背景

「分身」页签当前混了三层内容：值守会话卡片、全部群聊清单（「群聊 61 · 全部点开才拉」）、
已屏蔽会话，以及底部的「找群」「加入值守」两个搜索卡片。用户的实际用法只有两种：
看正在值守的会话，或搜一个人/一个群加进来；中间的群清单与页签目标无关，却占了最多篇幅。

同时按名字搜人时，结果行只显示 `open_id`（如 `ou_xxx`）。飞书 `contact +search-user`
返回的可读名称字段是 `localized_name`，`lib/im.js` 只挑了 `name` / `user_name`，
所以名称恒为空，界面退化成展示不可读的 imid。

## 目标与非目标

- 目标：分身页签只保留「正在值守的会话」；搜人与搜群合并成页签顶部的一个搜索框，
  结果只显示人类可读信息（名称、部门、群/私聊），不再展示 `open_id` / `chat_id`。
- 非目标：不改轮询节奏、值守判定、屏蔽语义与唤醒链路；不新增 API 路由；
  不改收件箱与服务对象页签。

## 方案

### 1. 搜索：一个输入框，两路结果合并

- 面板仍然并行调用现有 `/api/search`（人）与 `/api/search/chats`（群），前端合并、
  按「名称完全匹配 → 前缀匹配 → 其它」排序，按 `platform:chat_id` 去重。
- 结果行只渲染：名称、`群` / `私聊` 标签、部门（搜人时后端返回）、当前是否值守。
  没有可读名称的结果直接隐藏，并在有隐藏项时给一条提示。
- 「加入值守」用后端返回的 `chat_id`（飞书优先生成 `p2p_chat_id`）落库，人/群同一套按钮。
- 已屏蔽的搜索命中显示「已屏蔽 + 取消屏蔽」，避免点了加入却因屏蔽不生效。

### 2. 搜人结果带上可读名称

`lib/im.js` 的 `search()` 映射增加：

| 字段 | 来源（飞书） | 说明 |
| --- | --- | --- |
| `id` | `open_id` / `userid` / `user_id` / `id` | 兜底会话键 |
| `chat_id` | `p2p_chat_id` | 可直接用于拉消息/发消息的会话键，可空 |
| `name` | `localized_name` / `name` / `user_name` / `nickname` | 只回可读名称 |
| `department` | `department` | 展示用部门串，可空 |

`searchChats()` 的 `name` 不再回退到 `chat_id`：没有群名时回空串，由前端隐藏。

### 3. 分身后台只留守守会话

- 删除页签里的「群聊 N · 全部点开才拉」清单、`S.gAll` 展开态与「已屏蔽」清单。
- 已屏蔽会话的取消入口移到「设置 → 值守范围」，保留恢复能力。
- 值守中的群卡片补一个「定时检测 @我」开关，避免群清单删除后失去定时配置入口。

## 取舍

| 备选 | 否掉的理由 |
| --- | --- |
| 新增 `/api/search/all` 后端合并接口 | 两路搜索已有独立失败语义（企微没有群搜索），前端 `Promise.all` 合并即可，不动契约 |
| 保留群清单但默认折叠 | 用户要的是「只留值守」，折叠仍是噪声；需要找群时搜索更快 |
| 搜索结果显示 open_id 作为兜底 | 正是用户反馈的不可读信息；宁可隐藏无名结果 |

## 影响面

- 代码：`dsh-plugin/web/panel.js`（分身页签与搜索卡片）、`dsh-plugin/lib/im.js`
  （搜索字段映射）；`dsh-plugin/lib/client.js` 由 `scripts/build_client.py` 重新生成。
- 契约：不新增路由、不改入参；`/api/search` 响应增加 `chat_id` / `department` 为兼容性新增字段。
- 用户可见：分身页签、搜索行为、屏蔽恢复入口位置。
- 兼容：已有 `chats` 数据不变；用 `open_id` 加入的旧值守会话继续可用。

## 验收

- [x] 分身页签不再出现「群聊 N · 全部点开才拉」与已屏蔽清单。
- [x] 顶部一个搜索框；输入人名返回带名称/部门的行，界面不出现 `ou_` / `oc_` 串。
- [x] 输入群名返回群结果，群/人混排且可加入值守。
- [x] 值守中的群卡片可切换「定时检测 @我」。
- [x] 设置 → 值守范围能看到已屏蔽会话并取消屏蔽。
- [x] `node --test` 与 `bash scripts/gate.sh --quick` 全绿。

## 风险与回滚

- 风险：飞书搜索字段再次漂移时名称为空，结果被隐藏导致「搜不到人」。缓解：保留原始错误提示，
  无名结果计数提示；字段映射集中在 `im.js`。
- 回滚：还原 `web/panel.js` 与 `lib/im.js`，重跑 `scripts/build_client.py`；无状态迁移。
