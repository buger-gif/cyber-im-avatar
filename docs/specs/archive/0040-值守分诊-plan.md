## 原则

- 一步一验证，每步结束 `node --test` / `python3 tests/test_docs.py` 至少有一项证据；
  不把「代码写完再一起跑」留到最后。

  `tests/test_docs.py` 红。

### 6. 调度：`maybeTriage` / `maybeReview` / 配额

- `lib/poller.js`：
  - `tick()` 在 `maybeWarm()` 之后调 `maybeReview()` → `maybeTriage()`；一次 tick 最多一个
    desk turn；复核优先；
  - `maybeReview()`：`trial` 到期 → 只读探针 → `turns.triage(..., trigger=review)`；
    复核生成新 `event_id`/`event_at`、`attempts=0`，不写 `triaged_at`（不占每日配额）；
    `review_at+60min` 无合法决策 → 自动 `ignore`；非法/缺失先退回 `trial` 重试；
    `duty.enabled=false` 直接自动 `ignore`；
  - `maybeTriage()`：选最旧 `queued`；跳过 blocked/删除/非群/平台停用/`attempts>=2`/
    超过 24h（记 stale）；配额检查（`review` 与 manual 不计）；探针 → `turns.triage`；
    `duty.state=triaging`、`triaged_at=now`、`attempts+1`；
  - `turns` 的 `onDone` → 读决策 → `applyDecision`；缺失重试一次，仍缺失 `failed`；
  - 每次启动分诊/复核前先按当前 `event_id` 查决策文件；合法就直接应用，不再跑 turn
    （覆盖重启/回调丢失）；
  - desk turn 成功时 `desk.session_turns += 1`；达到 `duty.session_max_turns` 后由
    `resolveDesk()` 在下一个事件前换会话；
  - boot + 每日：`Duty.cleanupDecisions()` 清 7 天前未应用决策；`Duty.pruneRecords()`
    把 `ignore`/`failed` 超过 `duty.record_keep_days` 的记录清回 `state=none`；
    `policy.md` 不动；
  - `pollInfo()` / `doctor()` 增加队列、配额、值守台判断轮 `N / 上限` 与工作区。
- 测试：复核优先、一次一个、配额、stale、重启 `triaging→queued`、自动 off、失败重试、
  会话轮换、记录清理、`policy.md` 不被删。
- 验证：`cd dsh-plugin && node --test tests/poller.test.mjs tests/duty.test.mjs`。

### 10. 全量与真机

- `bash scripts/gate.sh`（全量：静态层 + Node 测试 + Python 测试）。
- 真机（用户）：
  1. 拉一个**不超过 10 人**的测试群进账号，群里 @ 自己；10 分钟内面板出现候选；
  2. 值守台判断 `watch` / `ignore`（默认 trial 关）；临时把 `trial_hours` 调到 24 再拉一个
     新群，确认可选 trial 也正常；分诊轮没有向群里发消息；
  3. 决定 watch 后群进入「分身实例」，接手轮正常；点「去会话」能看到值守台/群会话；
  4. 如果打开了 trial：到期复核后转正或自动结束；关掉 `duty.enabled` 后新群不再自动分诊，
     手动仍可；
  5. 把 `duty.session_max_turns` 临时调成 1、`record_keep_days` 调成 1：值守台换新会话、
     新首轮带最近判断、旧 `ignore` 记录被清；`policy.md` 仍在；用户项目 workspace 没有
     新增文件；最后把两个值改回默认；
  6. 留一个**基线之后新建的、未值守的新群**，隔 `sweep_min` 后在群里 @ 自己：面板出现
     「定期清查 @你」候选；已有群（`added_at <= baseline_at`）不在清查范围、不发请求；
     `@所有人` 不出现；同一条 @ 不重复；`sweep_min=0` 后不再出现。Feishu 确认只发一条
     `+messages-search --is-at-me`，不逐群拉；DingTalk 走逐新群回退。
  7. 拉一个 **11 人以上**的新群，在群里 @ 自己：自动候选只能 ignore（`group_too_large`），
     面板提示「只能手动开」；手动 watch 仍能成功。
