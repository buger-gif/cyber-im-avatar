## 2. 后端写接口

- `lib/app.js`：

  - `digest` 复用 helper；读改成 Buffer，`> 256 KiB` 截断并回 `truncated`。
  - `POST_ROUTES["/api/digest"] = "digestWrite"`。
  - `digestWrite`：校验 `text` 字符串、字节上限、`base_mtime` stale、空内容删文件、

## 3. 面板编辑态

- `web/panel.js`：
  - S 增加 `digestEdit` / `digestEditDate` / `digestDraft` / `digestEditBase` /
    `digestSaving` / `digestConflict`。
  - `loadDigest` / `refreshDigest` 在编辑态直接返回，`tick` 与 `digestTick` 因此不再刷。
  - 关注页顶部加「编辑」；`digestEditor()` 渲染 textarea + 保存/取消 + 冲突条；

  - `Esc` 取消编辑；空态也能进编辑；`truncated` 隐藏入口。
- 构建：`python3 scripts/build_client.py`。
- 验证：`node --check web/panel.js`、`node --check lib/client.js`；

## 4. 测试

- `tests/app.test.mjs` 加一组 `GET/POST /api/digest`：
  - 写入 → 读回同文；文件 600、目录 700、无 `.tmp` 残留。
  - 空白 → 删除；目录不存在时可创建。
  - 非法日期与穿越 → `bad_date`，目录外不动。
  - `utimes` 推后 mtime + 旧 `base_mtime` → `stale` 且文件不变；新 mtime → 成功。
  - 超 256 KiB → 拒绝；超限文件 GET → `truncated:true`。
