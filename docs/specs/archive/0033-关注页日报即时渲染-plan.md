- `loadDigest(date)`：缓存优先**同步渲染** → 后台重取；无缓存显示「正在读取日报…」。
- `refreshDigest()`：静默重取，只有 payload 变了才重绘；同一日期并发请求合并。
- 失败走 `setConnError("digest", …)`，保留上次内容；`bad_date` 单独提示。
- 「关注」页签可见时 3 秒静默刷新；`visibilitychange` / `focus` 回前台立即重取；
  `tick()` 与 `unmount` 同步改；重绘 body 前后保存/恢复 `.ims-scroll` 的 `scrollTop`。
- 验证：`node --check dsh-plugin/web/panel.js`；`python3 dsh-plugin/scripts/build_client.py`
