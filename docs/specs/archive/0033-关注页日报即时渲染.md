# 0033 关注页日报即时渲染

> 状态: 已验收
> 编号: 0033
> 版本: 0.14.0
> 关联: `docs/specs/contracts/01-api.md`（只读，本 spec 不改路由形状）

## 背景

「关注」页签显示 `~/.im-standin/digest/YYYY-MM-DD.md` 原文（spec 0019）：日报由 agent 写、
插件只读。用户反馈它「渲染太慢」，并给出标杆：**要和 DSH 自带的「工作区文件」页签一样快**。

现状与差距（隔离 DSH + 合成状态，400px 栏宽实测，2026-11-05）：

- **打开要等一次接口往返，且先闪假空态。** `mountPanel` 不预取日报；点「关注」时
  `paint()` 先按 `S.digest === null` 画成「今天还没有日报。agent 会在下次被唤醒时写…」，
  等 `/api/digest` 回来再 `paintBody()` 换成正文。渲染本身不慢（`paint` 4.1ms、接口
  0.7–2.1ms），但等待在宿主机主线程忙（对话流式输出）时会被拉长；把接口延迟放大到
  800ms 时，假空态挂了整整 825ms 才变正文。
- **原生文件页签是「点开即内容」。** 它把打开状态（含滚动位置）放在 store 里、直接走
  客户端 Remote 读，不经过空态占位；用户看到的差别就是「那边秒开、这边等一下」。
- **日报更新最多滞后 60 秒。** 唯一刷新点是 60 秒 `tick()`；agent 刚写完日报时，
  用户盯着「关注」页也看不到。
- **兜底刷新每次都整块重建 body。** 内容没变也重建 `<pre>` 与日期框，长日报的滚动位置
  被顶回顶部。

## 目标与非目标

- **目标**：打开「关注」页与 DSH 原生文件页同级——命中预热缓存时**同帧同步渲染、不发请求**；
  没缓存时显示「正在读取」而不是假空态；被查看时日报变化 3 秒内自动出现；内容没变不重建
  DOM、不动滚动位置。
- **非目标**：
  - 不改 `/api/digest` 契约（不加字段、不改返回形状），不改 `state.json`；
  - 不解析、不统计日报内容（铁律 8 不变，仍只把文件原文摊开）；
  - 不加 SSE / WebSocket / 新端口 / 新路由，不做后端文件监听推送（对齐原生文件页的「推送
    更新」留待将来，本轮用可见时短轮询）；
  - 不改 agent 写日报的协议与目录约定；
  - 不动分身 / 服务对象 / 体检 / 设置页签的刷新节奏。

## 方案

### 1. 模块级日报缓存 + 页面加载预热（`web/panel.js`）

- 缓存放在模块级（`mountPanel` / `mountSeat` 共用）：`date → payload`，最多 8 个日期，
  按插入顺序淘汰；失败结果不入缓存。右侧栏面板在中途重挂载时也能直接用上。
- **席位挂载（页面加载）就预热当天日报**：用户点「关注」时内容已在内存里；
  右侧栏面板晚一步挂载也直接读这份缓存。
- 打开页签 / 切日期时**先同步渲染缓存**，渲染完再后台重取；没有缓存才显示「正在读取日报…」。

### 2. 静默刷新（stale-while-revalidate）

- 命中缓存时同步渲染完立即发一次重取；返回内容与当前一致（`text` / `mtime` / `exists` /
  `error` 全等）就**不重绘**，滚动位置不动。同一日期的并发请求合并成一次。
- 「关注」页签可见（`S.tab === "attention"`、无会话详情、`document.visibilityState !== "hidden"`、
  面板有布局）时每 3 秒静默重取一次；页面重新可见 / 窗口重新聚焦时立即重取一次。
  本机读 1KB 文件，单次约 1ms，不产生对外请求。
- 原有 60 秒 `tick()` 里的关注页刷新保留，改用静默重取。

### 3. 状态与失败不装空

- 新增面板内状态：`digestLoading`（正在读的 date）、`digestError`、`digestInflight`
  （date → promise）、`digestTimer`。
- 读失败：`setConnError("digest", …)` 挂顶部错误条 + 重试入口；**保留上次内容**。
  已有内容时不显示任何「没有日报」的空态；没有内容时也不显示假空态，由错误条说明。
- `bad_date`（日期控件给不出合法日期）仍单独显示「日期格式不对」。

### 4. 渲染保持

- 重绘 body 前记录 `.ims-scroll` 的 `scrollTop`，重绘后恢复。
- 只有内容变化或首次加载完成才重绘，静默刷新无变化时零 DOM 变更。

## 取舍

| 备选 | 否掉的理由 |
| --- | --- |
| 后端加 ETag/304 省字节 | 本机读 1KB 文件，省传输不是瓶颈；多一个契约要维护 |
| 用 Remote 命名空间 / SSE 推送文件变化 | 插件不开端口、不加新路由（铁律 1）；本轮用可见时 3 秒轮询，体感已接近 |
| 把日报解析成结构化列表再渲染 | 破坏铁律 8 与 spec 0019 的「不解析」约定，格式一变就坏 |
| 只把 60 秒 tick 改成 3 秒 | 打开仍要等接口往返、仍先闪假空态，治不了「打开就慢」 |
| 打开时先画缓存但不再重取 | 看到的是页面加载时的旧内容，会误导 |

## 影响面

- 代码：`dsh-plugin/web/panel.js`（唯一事实源）、`dsh-plugin/lib/client.js`（构建产物，
  `python3 scripts/build_client.py`）。
- 契约：无路由 / 字段 / 配置键变化；`docs/specs/contracts/01-api.md` 只读不改。
- 用户可见：「关注」页签打开即显示、日报 3 秒内跟上、滚动位置不再被兜底刷新顶掉。
- 兼容：缓存是浏览器内存态，刷新即重建；老日报文件与 agent 写法不变。

## 验收

隔离 DSH（`DSH_HOME=/tmp/dshhome-bench`、`IM_STANDIN_DIR=/tmp/im-standin-bench`）+ 临时 CDP
脚本（不进仓库）实测，2026-11-05：

- [x] 面板冷启动后首次点「关注」→ 正文同步出现：把 `/api/digest` 延迟放大到 800ms，
      点页签到正文 **7ms**（改前同条件 825ms）；全程无「今天还没有日报」假空态。
- [x] 刷新页面后立刻点「关注」→ 先显示「正在读取日报…」（`loadingShown=true`、
      `falseEmptyShown=false`），接口回来再变正文。
- [x] 页面外改 `digest/<今天>.md`（追加一行）→ 不点任何按钮，**1.58 秒**后面板自动出现新行。
- [x] 日报内容不变时等 3 轮静默刷新 → `.ims-body pre` 是同一节点（`sameNode=true`），
      滚动到 300px 后 `scrollTop` 仍是 300。
- [x] 拦截接口回 500 → 正文保留（`contentKept=true`），顶部出现「本地服务连不上：拿不到日报 · 重试」，
      不出现「没有日报」；恢复后点「重试」错误条消失。
- [x] 切到没有文件的日期 → 「这一天没有日报」；点「回到今天」→ **0ms** 出内容，不闪假空态。
- [x] `node --check dsh-plugin/web/panel.js`、`python3 dsh-plugin/scripts/build_client.py`
      后 `lib/client.js` 含新代码；`node --test` 181/181；`bash scripts/gate.sh --quick` 的
      py-compile / js-check / secrets / 构建产物新鲜度全过。gate 里 `docs` 的红是并行会话
      在飞的 `SKILL.md` 等超预算（非本改动），当日 log 已记。

## 风险与回滚

- 风险：可见时每 3 秒读一次 1KB 文件（本机、无外部请求），成本可忽略；若将来宿主主线程紧张，
  重绘已收敛为「内容变化才重建」。
- 回滚：撤本 spec 的提交即可（纯面板内存态，无迁移、无落盘、无配置键）。
